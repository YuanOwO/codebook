## Floyd-Warshall Algorithm

全圖最短路徑  
圖上找任兩點都有最短路徑長

### 用法

1. `init(n)` 初始化 其中 `n` 為節點數
2. 輸入 `dis[u][v]`: 從 `u` 到 `v` 的原始距離
3. 呼叫 `floyd_warshall(n)` 算答案

### 結果

`dis[u][v]`: 從 `u` 到 `v` 的最短路徑長

### 時間複雜度

$O(n^3)$， 其中 $n$ 是節點數

### 備註

-   注意資料型態
-   如果有負環 `dis[u][u]` 會小於 $0$
-   `n = 1000` 仍可以在 $1$ 秒內跑完 (應該啦)
