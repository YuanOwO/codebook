## 線段樹 Segment Tree

### 用途

處理區間問題

### 用法

1.  初始化: 宣告 SegmentTree 結構時傳入 `vec`
2.  詢問區間問題: `query(l, r)`
3.  加值區間: `update(l, r, v)`

### 備註

0.  **不要什麼區間問題都想砸他**
1.  必須使用 1-base 的陣列
2.  如果要做單點 `x` 加值，可以寫 `update(x, x, v)`
3.  如果是要修改值變成 `v`，可以先剪掉原本的值再加回 `v`
4.  沒事不要亂改 `n` 會錯
5.  `NO_TAG` 的地方 需要懶人標記: `1`, 不需要懶人標記: `0`
6.  以下寫 KK 的地方我也不知道是 $[0, n-1]$ 還是 $[1, n]$
